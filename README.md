# ● Student Productivity & Placement Tracker

A modern, highly interactive dashboard built with **React.js** and **Tailwind CSS** designed to help students organize their daily coding routines, track contest reminders, and manage internship application pipelines in real-time.

## ● Key Features
- **Dynamic Task Management:** Check off completed tasks dynamically using filtering arrays.
- **Interactive Coding Contests:** Toggle-based reminders for upcoming LeetCode and Codeforces rounds.
- **Internship Tracker:** Update application stages instantaneously (e.g., from *Researching* to *Applied ✅*).
- **Clean UI/UX:** Styled using Tailwind CSS with beautiful rounded elements for modern scannability.

## ● Tech Stack
- **Frontend:** React.js (Functional Components & Hooks)
- **Styling:** Tailwind CSS
- **Build Tool:** Vite
- **Language:** JavaScript (ES6+)
